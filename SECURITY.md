# Security policy

If you find a security issue with belpire.com or this repository, please report it privately using **Security → Report a vulnerability** on this repository. Please don't open a public issue or post it in the Discord.

We'll acknowledge reports within a few days. This is a small community site run by volunteers, so there is no bug bounty, but we appreciate the help.

In scope: the website, its headers and the GitHub Actions workflows in this repository. Out of scope: Steam, Discord and Cloudflare themselves — report those to the respective vendor.
