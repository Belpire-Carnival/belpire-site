    How to Play on Discord

    Only the host needs to own the game

    1. Host starts the box

      Launch the pack on Steam and pick a game. Only the host needs to own it; everyone else plays free on their phone.

    2. Go Live in voice

      Join a Belpire voice channel, click Share Your Screen, pick the game window and turn on sound so everyone hears the host.

    3. Phones out

      Everyone opens jackbox.tv on a phone and types the four-letter room code from the host's screen. Each game gets a fresh code, so the host drops it in the voice chat every round.

    4. Room's full?

      Extra people join as the audience and still vote. Most games cap at 8 players; Bracketeering takes 16.

    Host tips

    • Extended timers in the game's settings help when the stream lags a few seconds behind.
    • Hide Room Code keeps randoms out if you're streaming somewhere public.
    • Family-friendly filtering is there when younger players join.
    • Trivia Murder Party 3 has online matchmaking, so it works without streaming.
